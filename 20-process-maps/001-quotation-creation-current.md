# Quotation Creation Process (Current / As-Is)

## Process Overview

- **Purpose:** Assemble a technical offer document (40-75+ pages) for a prospective steel plant customer.
- **Trigger:** A customer enquiry arrives for Rolling Mill or Billet Plant equipment.
- **End condition:** A complete PDF technical offer is ready for delivery to the customer.
- **Frequency:** 1-5 quotations per month. Low volume, high value.
- **Typical duration:** Quotations build up over time across multiple sessions. No single-sitting assembly.

## Roles Involved

| Role | Responsibility in This Process |
|---|---|
| Quotation preparer (2-3 staff) | Selects equipment items, assembles pages, edits project-specific fields |
| Suril Agarwal (Owner) | Reviews and approves final quotation before sending |

## Inputs

| Input | Source | Notes |
|---|---|---|
| Customer enquiry | Email, phone, or in-person | Specifies required mill capacity, product types, equipment needs |
| Equipment page sets | Local files (Word and PDF) | Pre-written technical descriptions per equipment item, ~5-6 pages each |
| Production table data | Excel spreadsheet | Capacity and rolling parameters specific to the project |
| Steefo letterhead template | Local files | Standard header, footer, company branding |
| Previous quotations | Local files | Used as reference for similar projects |

## Outputs

| Output | Destination | Notes |
|---|---|---|
| Technical offer PDF | Customer (via email or print) | 40-75+ pages depending on equipment selection |
| Quotation reference number | Internal tracking | Format: QTN-XXX (e.g., QTN-569) |

## Process Steps

### Main Flow

1. Customer enquiry arrives. Steefo staff reviews the requirements: mill capacity, product types, and equipment needed.
2. Staff assigns a project code (e.g., P480) and quotation number (e.g., QTN-569).
3. Staff opens a previous similar quotation as a starting template.
4. Staff edits the introduction page. Updates header, footer, and introduction text as needed.
5. Staff edits page 2 (Technical Parameters). Updates the 3 project-specific fields: mill production, basic raw material, and finished products.
6. Staff edits page 3 (Basic Data & Media Requirements). Updates the power requirement field.
7. Staff prepares the production table (page 4). Uses an Excel spreadsheet to calculate rolling parameters. Manually formats or copies the table into the quotation document.
8. Staff selects which equipment items to include based on customer requirements. Locates the corresponding page sets (Word/PDF files) from local storage.
9. Staff copies/inserts the selected equipment sections into the document. Each item adds ~5-6 pages. Typical selection: 5-6 items out of 15-20 available.
10. Staff assembles the Scope of Supply table. Starts from a default template. Adjusts S (Steefo) and C (Customer) responsibility assignments per project.
11. Staff edits the terms, conditions, and commercial pages. Starts from defaults. Modifies as needed for this project.
12. Staff selects applicable exclusion clauses and adds them to the exclusions page.
13. Staff reviews the entire document. Checks page numbering, formatting, and content consistency.
14. Staff updates the page numbers throughout the document (Page X of Y in header/footer).
15. Staff exports or prints the final document as PDF.
16. Suril reviews the quotation.
    - **If approved:** Quotation is sent to the customer. Go to step 17.
    - **If revisions needed:** Go to Exception A.
17. Staff sends the technical offer to the customer. Stores a copy locally with proper naming.

### Exception A: Revision Required

A1. Suril marks sections needing changes.
A2. Staff makes the edits in the document.
A3. Staff re-checks page numbering and formatting.
A4. Return to main flow at step 16.

### Exception B: New Version of Existing Quotation

B1. Customer requests changes or a revised offer after receiving the original.
B2. Staff opens the previous version of the quotation.
B3. Staff makes the required changes (swap items, update specs, adjust scope).
B4. Staff increments the version (e.g., QTN-542-R2 = revision 2).
B5. Staff re-does page numbering and formatting.
B6. Return to main flow at step 16.

## Connected Processes

- **Upstream:** Sales/enquiry process. Customer contacts Steefo with requirements.
- **Downstream:** Commercial negotiation. If the customer accepts the technical offer, commercial and payment terms follow.
- **Related:** Equipment catalog maintenance. Page sets need periodic updates when equipment specs change.

## Known Issues

| Issue | Impact | Current Workaround |
|---|---|---|
| Manual page assembly | Each quotation requires copying pages from multiple source files. Error-prone and time-consuming. | Staff uses previous quotations as templates to reduce work. |
| Page numbering is manual | Every time items are added or removed, page numbers must be updated throughout the entire document. | Staff manually updates headers/footers after assembly. |
| No version control | Previous versions may be overwritten or lost. No systematic tracking of which version was sent when. | Staff uses file naming conventions (QTN-542-R2) but no formal system. |
| No centralized catalog | Equipment page sets spread across individual machines. Different staff may have different versions. | No formal workaround. Staff coordinates informally. |
| Production table is manual | Excel calculations must be manually formatted into the quotation layout. | Copy-paste from Excel into Word. |
| Scope of Supply table is manual | S/C assignments must be manually adjusted per project. Easy to miss an item. | Staff starts from a previous similar quotation. |
